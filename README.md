# What factors are sales related to?
This web page draws on relevant data from the github project "Weather-and-Sales-Prediction-Analysis".

The data source is the sales data of an Irish Midlands fast food restaurant in Ireland from May 2021 to May 2024. Through visualization, you can view the changes in sales of each product and its relationship with the week and
day, correlation of underlying factors such as weather.

The demo link is accessible at https://jin0970.github.io/What-Effect-Sales/.
